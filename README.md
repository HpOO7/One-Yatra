# Ekam Journey

Landing page for Ekam Journey, a wellness centre in Rishikesh, Uttarakhand offering breathwork, meditation, healing and retreat programs.

A single self-contained static page (`index.html` + `media/`) — no build step required.

## Local preview

Just open `index.html` in a browser, or serve it locally:

```
python3 -m http.server 8000
```

then visit `http://localhost:8000`.
